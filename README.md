# qweCMS

> **Просто CMS. Просто qwe.**

![Лягушка-редактор](https://img.icons8.com/color/48/frog.png)  
*qweCMS — как первые три клавиши на клавиатуре: очевидно, удобно, без лишнего.*

---

### 💡 Зачем это нужно?
Большинство CMS — это лабиринты настроек, плагинов и обновлений.  
**qweCMS** — для тех, кто хочет просто публиковать контент, а не настраивать космический корабль.

- ✅ Минималистичный интерфейс  
- ✅ Markdown-поддержка "из коробки"  
- ✅ Нет зависимостей от облаков или маркетплейсов  
- ✅ Открытый исходный код (MIT)

---
