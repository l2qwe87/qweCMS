# План разработки qweCMS

## Обзор

План разработки headless CMS с динамическими схемами контента на основе миксинов. Реализация на .NET + Angular + MongoDB с развертыванием в Docker.

## 🐳 Docker архитектура

```
┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│   MongoDB   │  │  .NET API   │  │  Angular    │
│   (база)    │  │ (бэкенд)    │  │ (фронтенд)  │
│  Port:27017 │  │  Port:5000  │  │  Port:4200  │
└─────────────┘  └─────────────┘  └─────────────┘
```

## 📋 План разработки

### 🔥 Фаза 1: Инфраструктура (HIGH приоритет)

#### 1. Настроить Docker инфраструктуру
- **Задача:** Создать docker-compose.yml с 3 контейнерами
- **Компоненты:**
  - MongoDB контейнер с volume для данных
  - .NET API контейнер с development конфигурацией
  - Angular контейнер с hot reload
- **Результат:** Готовая среда для разработки

#### 2. Создать структуру .NET solution
- **Задача:** Настроить проекты в solution
- **Проекты:**
  - `QweCMS.Api` - Web API
  - `QweCMS.Core` - бизнес-логика и модели
  - `QweCMS.Infrastructure` - работа с MongoDB
  - `QweCMS.Tests` - unit тесты
- **Результат:** Базовая структура .NET приложения

#### 3. Настроить MongoDB подключение
- **Задача:** Настроить взаимодействие с MongoDB
- **Компоненты:**
  - MongoDB.Driver настройка
  - Базовые репозитории
  - Connection string конфигурация
- **Результат:** Работающее подключение к базе данных

#### 4. Реализовать модели данных
- **Задача:** Создать модели для Schema и Mixin
- **Модели:**
  - `MixinEntity` - модель миксина
  - `SchemaEntity` - модель схемы с миксинами
  - Базовые поля (CreatedAt, UpdatedAt)
- **Результат:** Модели для работы с коллекциями

#### 5. Создать Angular проект
- **Задача:** Настроить структуру Angular приложения
- **Модули:**
  - `SchemaModule` - управление схемами
  - `ContentModule` - управление контентом
  - `PublicModule` - публичная часть
  - `CoreModule` - общие сервисы
- **Результат:** Базовая структура Angular приложения

### ⚡ Фаза 2: Основной функционал (MEDIUM приоритет)

#### 6. Реализовать CRUD API для миксинов
- **Эндпоинты:** GET, POST, PUT, DELETE `/api/mixins`
- **Валидация:** JSON Schema валидация миксинов
- **Результат:** Полный API для управления миксинами

#### 7. Реализовать CRUD API для схем
- **Эндпоинты:** GET, POST, PUT, DELETE `/api/schemas`
- **Особенности:** Валидация связей с миксинами
- **Результат:** Полный API для управления схемами

#### 8. Реализовать сервис компоновки схем
- **Задача:** SchemaCompositionService с JSON Pointer
- **Функционал:**
  - Компоновка схем из миксинов
  - Вложенное размещение по путям
  - Валидация путей миксинов
- **Результат:** Динамическая генерация схем

#### 9. Создать интерфейс управления миксинами
- **Компоненты:**
  - Список миксинов с пагинацией
  - Форма создания/редактирования
  - JSON Schema редактор
- **Результат:** Административный интерфейс для миксинов

#### 10. Создать интерфейс управления схемами
- **Компоненты:**
  - Список схем с фильтрацией
  - Конструктор схем с миксинами
  - Предпросмотр скомпонованной схемы
- **Результат:** Административный интерфейс для схем

#### 11. Реализовать CRUD API для контента
- **Особенности:**
  - Динамические коллекции `content_{schemaName}`
  - Валидация по скомпонованной схеме
  - Поддержка связей `$ref`
- **Результат:** API для управления контентом

#### 12. Создать интерфейс управления контентом
- **Компоненты:**
  - Динамические формы из JSON Schema
  - Списки контента с фильтрацией
  - Редактор с preview
- **Результат:** Интерфейс для управления контентом

#### 13. Реализовать систему связей
- **Задача:** ReferenceService для работы с `$ref`
- **Функционал:**
  - Разрешение ссылок между документами
  - Каскадные удаления
  - Проверка циклических ссылок
- **Результат:** Работающая система связей

#### 14. Добавить аутентификацию и авторизацию
- **Компоненты:**
  - JWT токены для аутентификации
  - RBAC для разграничения прав
  - Middleware для проверки токенов
- **Результат:** Безопасная система с ролями

### 🎯 Фаза 3: Дополнительный функционал (LOW приоритет)

#### 15. Создать публичную часть сайта
- **Компоненты:**
  - Отображение контента по схемам
  - Навигация и SEO оптимизация
  - Адаптивный дизайн
- **Результат:** Публичный сайт для просмотра контента

#### 16. Реализовать экспорт контента
- **Форматы:** HTML, PDF
- **Функционал:** Генерация статических файлов
- **Результат:** Возможность экспорта контента

#### 17. Настроить production Docker
- **Оптимизации:**
  - Multi-stage builds для уменьшения размера
  - Health checks для контейнеров
  - Environment variables конфигурация
- **Результат:** Production-ready конфигурация

#### 18. Написать unit тесты
- **Область:** Основные сервисы и API
- **Инструменты:** xUnit, Moq
- **Результат:** Покрытие ключевой логики тестами

#### 19. Создать документацию
- **Разделы:**
  - Развертывание и настройка
  - Использование административного интерфейса
  - API документация
- **Результат:** Полная документация проекта

5. ✅ Базовая аутентификация и авторизация
